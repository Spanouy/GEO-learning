# GEO Overview

## What is GEO?

The Gene Expression Omnibus (GEO) is a public functional genomics data repository maintained by the National Center for Biotechnology Information (NCBI).

GEO provides access to publicly available array- and sequence-based functional genomics data and associated experimental information.

## Main purpose

GEO allows researchers to:

* Search for public gene expression datasets
* Explore experimental and sample information
* Download raw and processed data
* Reuse public datasets for bioinformatics analysis

## Key concepts

* GSE — Series
* GSM — Sample
* GPL — Platform
* GDS — Dataset
* GEO Profiles — Gene expression profiles
