# GEO-learning

Learning and practical notes on the NCBI Gene Expression Omnibus (GEO) and gene expression data analysis.

## Topics

* Introduction to GEO
* GEO DataSets and Series
* GSE, GSM, GPL, and GDS
* GEO metadata and experimental design
* Raw and processed data
* GEO file formats
* Microarray and RNA-seq data
* GEOquery and programmatic data access
* Practical GEO dataset evaluation

## Practical Example

A practical example using a GEO breast cancer dataset will be included to demonstrate how to explore, download, and evaluate GEO data.

## Goal

This repository documents my learning process and practical experience with GEO and public gene expression datasets.
